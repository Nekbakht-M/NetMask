# План: NetMask — IP калькулятор (Android → компьютер)

Образец: [calculator.net — IP Subnet Calculator](https://www.calculator.net/ip-subnet-calculator.html?cclass=b&csubnet=30&cip=192.168.1.1&ctype=ipv4&x=Calculate)
Скриншоты-образцы: `plan/references/` (форма, список масок, результат IPv4, список сетей).

## Принятые решения (можно поменять)
- **Технология:** Flutter. Один код даёт Android сейчас и Windows/Linux/macOS потом, без переписывания.
- **Языки:** таджикский (основной, по умолчанию), русский, английский. Выбор сохраняется на устройстве и восстанавливается при следующем запуске.
- **Дизайн (по ui-ux-pro-max):** тёмная тема по умолчанию + светлая, шрифты JetBrains Mono (адреса, маски) и IBM Plex Sans (текст), зелёный акцент как у терминала, крупные кнопки ≥ 48dp.
- **Название:** NetMask. **Иконка:** окно терминала «>_ IP» (вариант 6). Автор: Neka, Telegram @Neka_m.
- **Код:** https://github.com/Nekbakht-M/NetMask
- **Работает без интернета**, все расчёты внутри приложения.

## Экран и функции

### Раздел 1. IPv4 (вкладка)
Ввод:
- Класс сети: Любой / A / B / C. Он ограничивает список масок: A → /8…/32, B → /16…/32, C → /24…/32, Любой → /1…/32.
- Подсеть: выпадающий список в формате `255.255.255.252 /30`.
- IP-адрес: поле ввода с проверкой (4 октета, 0–255).
- Кнопки «Calculate» и «Очистить».
- Ошибка под заголовком, если IP неверный (например «Пожалуйста, укажите IP-адрес достаточной длины»).

Результат (таблица, как в образце):
IP-адрес, сетевой адрес, диапазон адресов для хостов, широковещательный адрес, общее количество хостов, количество доступных хостов, маска подсети, wildcard-маска, двоичная маска, класс IP, CIDR, тип IP (частный/публичный), короткая запись.
Дополнительные поля (Binary ID, Integer ID, Hex ID, in-addr.arpa, IPv4-mapped адрес, 6to4 префикс) **скрыты** и раскрываются кнопкой «Подробнее ▾», чтобы не перегружать экран.
Каждое значение копируется долгим нажатием (удобно для админов).

### Раздел 2. IPv6 (вкладка)
Ввод: длина префикса /1…/128 (по умолчанию /64), IP-адрес, кнопки «Calculate» и «Очистить».
Результат: IP-адрес с префиксом, полный адрес, общее количество адресов, сеть, диапазон адресов.

### Список возможных сетей (отдельная кнопка)
Кнопка «Все сети» под результатом IPv4 открывает отдельный экран: «Все 64 из возможных /30 сетей для 192.168.1.*». Короткий заголовок «Все сети /30» и подпись «64 сети · 192.168.1.*», список карточками (сеть, хосты, широковещательный), своя сеть подсвечена, кнопка «К моей сети».
Кнопка **«Поделиться (Excel)»**: создаёт файл `NetMask_<сеть>_<префикс>.xlsx` (столбцы: №, сеть, CIDR, диапазон хостов, широковещательный, маска, доступные хосты) и открывает меню «Поделиться» Android (Telegram, WhatsApp, почта, сохранить). Также «Копировать для Excel» — таблица в буфер обмена.

### Настройки (кнопка ⚙ в верхней панели)
- Язык: Тоҷикӣ / Русский / English (запоминается).
- Тема: тёмная / светлая / как в системе.
- Раздел при запуске: IPv4 или IPv6.
- Всегда показывать дополнительные поля (вкл/выкл).
- Запоминать последний введённый IP и маску.
- История расчётов (последние 20, можно очистить).
- О программе: автор (Neka), версия, ссылка на Telegram.

### Автор и аккуратная реклама
- В «О программе»: «Создатель: …», кнопка «Написать в Telegram».
- Реклама про **создание сайтов и программ**, без полосы на главном экране:
  - В «Настройках» отдельная карточка «Разработчик»: фото/логотип, «Создаю сайты, Android-приложения и программы для бизнеса», примеры работ, кнопка «Заказать в Telegram».
  - На экране «О программе» строка «Нужен свой сайт или приложение? Напишите мне» с кнопкой Telegram.
  - Один раз, после 10-го расчёта, всплывающая карточка «Понравилось приложение? Я делаю такие на заказ», с кнопками «Написать» и «Не показывать». Больше не появляется.
- Кнопка «Поделиться» (IPv4 и IPv6): окно с полным результатом (все поля, доп. поля если раскрыты), варианты «Копировать текст» и «Как Excel» (файл `NetMask_<сеть>_<префикс>.xlsx`), подпись «— NetMask · Создатель: Neka». Открывает меню «Поделиться» Android.

2. ✅ Утвердить план, название, иконку, репозиторий.
3. ✱ Дизайн-макет экранов (IPv4, IPv6, список сетей, выбор языка) в виде веб-превью для согласования.
4. ○ Ядро расчётов IPv4/IPv6 + автотесты, сверка с calculator.net.
5. ○ Интерфейс Flutter по утверждённому макету + переводы TJ/RU/EN.
6. ○ **Спросить разрешение →** сборка APK для Android, проверка на телефоне.
7. ○ Исправления по замечаниям.
8. ○ **Спросить разрешение →** сборка версии для компьютера.

Правило: перед каждой сборкой программы — спрашивать у Neka.
